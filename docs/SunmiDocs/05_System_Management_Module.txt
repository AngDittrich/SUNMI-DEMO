设置PCI24小时重启时间
原型
int set24HourRebootRegular(int type,int hour,int minute,int second);
原型 | int set24HourRebootRegular(int type,int hour,int minute,int second);
功能
在金融设备上设置PCI24小时重启时间(针对设置-安全中心-24小时重启项设置)
功能 | 在金融设备上设置PCI24小时重启时间(针对设置-安全中心-24小时重启项设置)
参数
type
 
1： 原重启模式，保持原有PCI安全钟的定时重启，从开始时间算起，23小时后开始弹框提醒用户重启；当设为模式1时，时分秒参数不做解析，可填任意值。
2：定时重启，以用户设置的时间重启。当设为模式2时，时分秒参数必须填写，且必须为24小时制。重启时，弹框提醒，倒计时一分钟，可取消，总共三次取消机会，每次弹框间隔5分钟，第四次弹框倒计时结束后会强制重启。每次开机后仅第一次设置时间有效，后续重复设置如果时间与开机第一次设置时间不一致，将返回1，表示模式切换成功，时间设置未生效。
参数 | type   | 1： 原重启模式，保持原有PCI安全钟的定时重启，从开始时间算起，23小时后开始弹框提醒用户重启；当设为模式1时，时分秒参数不做解析，可填任意值。 2：定时重启，以用户设置的时间重启。当设为模式2时，时分秒参数必须填写，且必须为24小时制。重启时，弹框提醒，倒计时一分钟，可取消，总共三次取消机会，每次弹框间隔5分钟，第四次弹框倒计时结束后会强制重启。每次开机后仅第一次设置时间有效，后续重复设置如果时间与开机第一次设置时间不一致，将返回1，表示模式切换成功，时间设置未生效。

返回值
1: 模式切换成功，时间设置失败(仅当入参type=2时候，非开机第一次设置时间且设置的时间与第一次不一致时候将返回)

-1: 接口调用失败(参数错误等)

-41:未找到系统服务，请联系设备供应商
