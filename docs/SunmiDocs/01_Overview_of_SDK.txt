2. 概述
2.1 引言
SunmiCustomer API SDK是Sunmi基于Android系统封装的贴近java开发者的一套调用设备系统能力的接口，开发者通过该SDK可以快速调用Sunmi设备系统相应接口，实现自己相关的业务逻辑开发。
SDK主要包含：设备信息模块、设备管理模块、软件管理模块、系统管理模块、系统UI管理模块、设备运行时信息模块、网络管理模块、设备软件信息模块。
2.1.1 名词解释
API 详情里的接口有适用范围区分，以下是相关定义：
金融通用
：仅适用于金融 P 系列产品。（
见附录7.2金融支持的产品型号
）
非金融通用
：适用于非金融 D、T、S、K、F 系列产品。（
见附录7.1非金融支持的产品型号
）
通用
：无限制，金融与非金融产品均可使用。
指定机型：
该接口仅适配了当前列出的机型。
2.2 快速集成SunmiCustomerAPI SDK
2.2.1 快速集成商米支付SDK
本文是SunmiCustomer API SDK标准的集成开发指南文档。用以指导SDK的使用方法，默认读者已经熟悉IDE（AndroidStudio）的基本使用方法，具有一定的Android 编程基础。目前本文档仅适用于商米非金融设备的三代机，使用SDK前，请务必仔细阅读该文档。使用前请检查以下前提条件：
本地依赖导入
将SUNMI_CUSTOMER_API_vx.x.x_release.aar文件放在libs目录下。
在项目根目录的build.gradle中增加以下代码：
buildscript {
	repositories {
		mavenCentral()
	}
}

allprojects {
    repositories {
        mavenCentral()
    }
}
在app/build.gradle中增加以下代码：
implementation files('libs/SUNMI_CUSTOMER_API_v1.x.x_release.aar')
导入aar包完成后，重新build项目。
2.2.2 SDK所支持的系统版本以及IDE
目前SDK支持API-19(Android 4.4+)
目前SDK只支持Android studio、Intellij的集成
2.3 
使用Sunmi Customer API
最佳实践:推荐在Applicaiton的onCreate()初始化API对象，通过进程全局唯一的引用对象调用API。请注意，绑定SunmiCustomerServiced服务为异步回调，请注意在回调连接成功后才能使用API。出现绑定SunmiCustomerServiced失败请先检查设备是否已经安装SunmiCustomerService。其次在项目AndroidManifest清单文件中添加
 <queries>
        <package android:name="com.sunmi.tmservice"/>
 </queries>
然后重新尝试。

TMSApi sTmsApi = new TMSApi();

public class FileStorageUtil {
    /**
     * 获取兼容性的外部存储文件路径
     *
     * @param context      应用上下文
     * @param externalPath 外部存储路径（如/sdcard/xxx.apk）
     * @return 兼容当前系统版本的安全文件路径
     */
    public static String getCompatibleExternalPath(Context context, String externalPath) {
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.Q) {
            // Android 10及以上版本，需要将文件复制到应用内部存储
            return copyToAppInternalStorage(context, externalPath);
        } else {
            // Android 10以下版本可以直接使用外部存储路径
            return externalPath;
        }
    }

    /**
     * 将外部存储文件复制到应用内部存储目录
     *
     * @param context      应用上下文
     * @param externalPath 外部存储文件路径
     * @return 应用内部存储中的文件路径
     */
    private static String copyToAppInternalStorage(Context context, String externalPath) {
        try {
            File sourceFile = new File(externalPath);
            if (!sourceFile.exists()) {
                return null;
            }

            // 创建应用内部存储目录
            File internalDir = new File(context.getFilesDir(), "external_copied");
            if (!internalDir.exists()) {
                internalDir.mkdirs();
            }

            // 目标文件路径
            File targetFile = new File(internalDir, sourceFile.getName());

            // 复制文件
            copyFile(externalPath, targetFile.getAbsolutePath());

            return targetFile.getAbsolutePath();
        } catch (Exception e) {
            e.printStackTrace();
            return null;
        }
    }

    /**
     * 文件复制工具方法
     *
     * @param sourcePath 源文件路径
     * @param targetPath 目标文件路径
     * @throws IOException 文件操作异常
     */
    private static void copyFile(String sourcePath, String targetPath) throws IOException {
        try (FileInputStream fis = new FileInputStream(sourcePath);
             FileOutputStream fos = new FileOutputStream(targetPath);
             FileChannel sourceChannel = fis.getChannel();
             FileChannel targetChannel = fos.getChannel()) {
            targetChannel.transferFrom(sourceChannel, 0, sourceChannel.size());
        }
    }

    /**
     * 清理复制的外部文件
     *
     * @param context 应用上下文
     */
    public static void cleanCopiedExternalFiles(Context context) {
        File internalDir = new File(context.getFilesDir(), "external_copied");
        if (internalDir.exists()) {
            File[] files = internalDir.listFiles();
            if (files != null) {
                for (File file : files) {
                    file.delete();
                }
            }
        }
    }

    /**
     * 检查外部存储是否可用
     *
     * @return 外部存储是否可读写
     */
    public static boolean isExternalStorageAvailable() {
        String state = Environment.getExternalStorageState();
        return Environment.MEDIA_MOUNTED.equals(state);
    }

    /**
     * 获取标准的外部存储目录路径
     *
     * @return 外部存储根目录路径
     */
    public static String getExternalStoragePath() {
        return Environment.getExternalStorageDirectory().getAbsolutePath();
    }
}

 * 物理小区 ID（PCI）。
 *
 * 表示当前 arfcn 频点上的具体小区标识。
 *
 * 常见范围：
 * NR：0 ~ 1007
 * LTE：0 ~ 503
 *
 * -1 表示不可用。
 */
public int pci = -1;

/**
 * 频段号。
 *
 * 是一个正整数，其具体含义取决于无线制式。
 *
 * 例如：
 * 3：LTE Band 3，大约 1800 MHz
 * 41：LTE Band 41 或 NR n41
 * 78：NR n78，大约 3.5 GHz
 *
 * -1 表示不可用。
 */
public int band = -1;

/**
 * RSRP，参考信号接收功率。
 *
 * 单位：dBm。数值越大、越接近 0，表示信号越强。
 *
 * 常见参考：
 * >= -70 dBm：极好
 * -70 ~ -85 dBm：很好
 * -85 ~ -95 dBm：良好
 * -95 ~ -110 dBm：一般
 * -110 ~ -120 dBm：较差
 * < -120 dBm：很弱
 *
 * 理论范围通常大约是 -156 ~ -44 dBm。
 * -1 表示不可用。
 */
public int rsrp = -1;

/**
 * RSRQ，参考信号接收质量。
 *
 * 单位：dB。反映信号质量，需要结合无线制式一起理解。
 *
 * 典型范围：
 * LTE：-19.5 ~ -3 dB
 * NR：-43 ~ +20 dB
 *
 * 常见 NR 参考：
 * >= -8 dB：极好
 * -8 ~ -12 dB：良好
 * -12 ~ -16 dB：一般
 * -16 ~ -20 dB：较差
 * < -20 dB：很差
 *
 * -1 表示不可用。
 */
public int rsrq = -1;

/**
 * SINR，信号与干扰加噪声比。
 *
 * 单位：dB。数值越大，表示干扰越低，网络质量越好。
 *
 * 常见参考：
 * >= 20 dB：极好
 * 13 ~ 20 dB：很好
 * 6 ~ 13 dB：良好
 * 0 ~ 6 dB：一般
 * -10 ~ 0 dB：较差
 * < -10 dB：很差
 *
 * 理论范围大约是 -20 ~ +40 dB。
 * -1 表示不可用。
 */
public int sinr = -1;

/**
 * 信号等级。
 *
 * 取值范围：
 * 4：极好
 * 3：良好
 * 2：一般
 * 1：较差
 * 0：无信号
 * -1：不可用
 *
 * 含义与系统信号格一致。
 */
public int signalLevel = -1;

/**
 * 网络模式。
 *
 * 用于描述当前或配置的网络模式字符串，例如：
 * "NR/LTE"、"仅 LTE"、"WCDMA 优先" 等。
 *
 * 具体格式取决于实现方式。
 * null 表示不可用。
 */
public String networkMode = null;

/**
 * 当前网络类型。
 *
 * 表示设备当前驻留的单一网络类型。
 * 一次只返回一个值，不会组合多个值。
 * 取值通常对应 Android TelephonyManager.NETWORK_TYPE_*。
 *
 * 可用于判断当前网络是 5G / 4G / 3G / 2G。
 *
 * -1 表示不可用。
 */
public int currentNetworkType = -1;

/**
 * 允许使用的网络类型位掩码。
 *
 * 表示设备或当前订阅允许使用的网络类型集合。
 * 取值通常对应 Android TelephonyManager.NETWORK_TYPE_BITMASK_*。
 *
 * 与 currentNetworkType 的区别：
 * currentNetworkType 表示当前正在使用的单一网络类型。
 * allowedNetworkTypesBitmask 表示配置上允许使用的多个网络类型集合。
 *
 * 0L 表示不可用或为空。
 */
public long allowedNetworkTypesBitmask = 0L;

/**
 * 当前运营商名称。
 *
 * 例如：中国移动。
 *
 * 表示当前已注册网络的运营商名称，
 * 不一定等同于 SIM 卡所属的归属运营商。
 */
public String operatorName = null;

/**
 * 当前已注册网络的 MCC+MNC（PLMN）。
 *
 * 表示设备当前连接到的网络运营商代码，
 * 也就是当前注册的 PLMN。
 * 格式通常是 5 位或 6 位数字字符串。
 *
 * 例如：
 * 46000 / 46002 / 46007：不同制式或场景下的中国移动
 * 46001 / 46006：中国联通
 * 46003 / 46011：中国电信
 * 310260：美国 T-Mobile
 * 310410：美国 AT&T
 * 23415：英国 Vodafone
 * 44010：日本 NTT DOCOMO
 * 45005：韩国 SKT
 * 52501：新加坡 Singtel
 *
 * 说明：
 * 在本地网或未漫游时，它可能与 simOperatorNumeric 相同。
 * 在国内或国际漫游时，它可能与 simOperatorNumeric 不同。
 * 通常在无网络服务时为空。
 */
public String networkOperatorNumeric = null;

/**
 * SIM 卡所属运营商的 MCC+MNC。
 *
 * 表示 SIM 卡本身归属的运营商代码，而不是当前注册网络。
 *
 * MCC = Mobile Country Code，移动国家代码，为 3 位数字。
 * MNC = Mobile Network Code，移动网络代码，为 2 到 3 位数字。
 *
 * 中国常见示例：
 * 46000：中国移动（GSM）
 * 46001：中国联通（GSM）
 * 46002：中国移动（TD-SCDMA）
 * 46003：中国电信（CDMA）
 * 46007：中国移动（4G/5G）
 * 46006：中国联通（4G/5G）
 * 46011：中国电信（4G/5G）
 *
 * 简单理解：
 * MCC = 国家
 * MNC = 运营商
 */
public String simOperatorNumeric = null;

/**
 * SIM 卡状态。
 *
 * 常见取值范围：0 ~ 8。
 *
 * 0：SIM_STATE_UNKNOWN，未知
 * 1：SIM_STATE_ABSENT，未插卡
 * 2：SIM_STATE_PIN_REQUIRED，需要 PIN
 * 3：SIM_STATE_PUK_REQUIRED，需要 PUK
 * 4：SIM_STATE_NETWORK_LOCKED，网络锁定
 * 5：SIM_STATE_READY，就绪
 * 6：SIM_STATE_NOT_READY，已插卡但未就绪
 * 7：SIM_STATE_PERM_DISABLED，永久禁用
 * 8：SIM_STATE_CARD_IO_ERROR，卡 I/O 错误
 * -1：不可用
 *
 * 一个简单记忆方式：
 * 0 未知，1 未插卡，2 PIN，3 PUK，4 锁定，5 就绪，6 未就绪，7/8 故障。
 */
public int simState = -1;

6.3 OnInstallAppListener
1. 安装成功将会回调onInstallFinished与onInstallSuccess。任选其一判定为安装成功即可。
2. 安装失败将会回调onInstallError与onInstallFail。错误码一致，任选其一判定为安装失败即可。
interface OnInstallAppListener {
  
        /**
        * 安装完成
        */
       void onInstallFinished();
  
        /**
        * 安装错误
        * @param errorId 错误码，详见4.2静默安装应用错误码
        */
       void onInstallError(int errorId);
  
        /**
        * 安装成功
        * @param packagename 包名
        */
       void onInstallSuccess(String packagename);
       
        /**
        * 安装失败
        * @param packagename 包名，可能为空
        * @param errorId 错误码，详见4.2静默安装应用错误码
        */
       void onInstallFail(String packagename,int errorId);
}
