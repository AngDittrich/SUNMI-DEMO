0 ：退出霸屏时切换为使用四位长度的密码
1 ：退出霸屏时切换为使用八位长度的密码

参数 | int type | -1 ：回到商米原逻辑 0 ：退出霸屏时切换为使用四位长度的密码 1 ：退出霸屏时切换为使用八位长度的密码 2 ：退出霸屏时切换为使用本地密码

备注
1、默认是商米原逻辑，如果同时存在本地密码和云端密码，则允许同时使用本地密码和云端密码退出霸屏，默认会选择在本地密码界面，可手动切换到云端密码界面。
2、切换操作，则切换到哪种模式，就使用哪种密码退出霸屏模式，切换操作不会清除原有设置的密码。

备注 | 1、默认是商米原逻辑，如果同时存在本地密码和云端密码，则允许同时使用本地密码和云端密码退出霸屏，默认会选择在本地密码界面，可手动切换到云端密码界面。 2、切换操作，则切换到哪种模式，就使用哪种密码退出霸屏模式，切换操作不会清除原有设置的密码。 3、切换到哪种类型，要预先调用setKioskPwdByType(int type, String psw)接口后，才能正常切换到目标类型。
